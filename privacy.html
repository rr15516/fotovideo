Norme sulla privacy di FotoVideo

Ultimo aggiornamento: 2 novembre 2026

Quali dati utilizza l’applicazione

FotoVideo accede a Google Foto solo tramite la Picker API di Google, con l’autorizzazione di sola lettura photospicker.mediaitems.readonly. L’applicazione può leggere unicamente le foto che l’utente seleziona in modo esplicito durante la sessione di selezione. Non ha accesso al resto della libreria.

Come vengono trattati i dati

Le foto selezionate vengono scaricate direttamente nel browser dell’utente ed elaborate sul suo dispositivo per creare il video. Non vengono inviate, caricate o conservate su alcun server dello sviluppatore né condivise con terze parti. L’applicazione non utilizza cookie di profilazione, strumenti di analisi o pubblicità.

Il token di accesso fornito da Google resta nella memoria della scheda del browser e non viene salvato. Nel browser viene memorizzato solo l’ID client dell’applicazione, per evitare di reinserirlo.

Uso limitato dei dati

L’uso e il trasferimento a qualsiasi altra app delle informazioni ricevute dalle API di Google rispetteranno le norme sui dati utente dei servizi API di Google (Google API Services User Data Policy), inclusi i requisiti di uso limitato (Limited Use).

Revoca dell’accesso

L’utente può revocare in qualsiasi momento l’accesso di FotoVideo al proprio account Google da myaccount.google.com/permissions.
